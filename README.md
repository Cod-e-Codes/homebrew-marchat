# homebrew-marchat

Official [Homebrew](https://brew.sh/) tap for [marchat](https://github.com/Cod-e-Codes/marchat), maintained by the project. Formulas live here rather than in `homebrew-core`; users add this tap to install.

## Install

```bash
brew tap cod-e-codes/marchat
brew install marchat
```

This installs `marchat-client` and `marchat-server` from published GitHub release archives.

Canonical templates and release checklist: [marchat `packaging/homebrew/`](https://github.com/Cod-e-Codes/marchat/tree/main/packaging/homebrew) and [PACKAGING.md](https://github.com/Cod-e-Codes/marchat/blob/main/PACKAGING.md).
